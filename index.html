Voir les ligues proposées

Ligues & terrains mis à disposition

Deux terrains de Robot Soccer Kit et un terrain de Rescue, voire plus selon le nombre d'équipes.

2 terrains prévus

Robot Soccer Kit (RSK)

Du football de robots avec des machines identiques : la différence se joue sur le code. Suivi par caméra, API Python.

  • Parfait pour débuter : pas de mécanique à construire
  • Matchs courts, idéaux pour un tournoi amical improvisé
  • Robots de démonstration disponibles sur place
1 terrain prévu

Rescue

Un robot autonome suit une ligne, franchit des obstacles et retrouve des victimes dans une zone d'évacuation.

  • Parcours modulable selon les niveaux
  • Idéal pour tester son robot avant la saison
  • Échanges de solutions entre équipes encouragés
Peut-être plus…

D'autres ligues ? À vous de nous le dire

OnStage, Soccer standard, Maze… Si assez d'équipes le demandent, le terrain correspondant pourra être monté. Indiquez-le dans le formulaire.
